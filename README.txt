CLASSICAL AI REASONING AGENT
============================
Name: SAHIL SIHAG    ID: M26MAC008

Natural-language knowledge base -> symbolic representation -> classical reasoning -> True / False
No machine-learning or generative AI model is used at any stage.

Files
-----
reasoning_agent.ipynb  complete implementation (run top to bottom); prints accuracy and inference time
report.pdf             representation, algorithms, experiments, reasoning traces
submission.csv         predictions, columns: id,flag  (True / False)
README.txt             this file

How to run on a private test set
---------------------------------
Requirements: Python 3.9+, pandas, reportlab, matplotlib (the first cell installs them with pip; datasets and
huggingface_hub are only used to download the public data and are optional).

Google Colab
  1. Upload reasoning_agent.ipynb (File -> Upload notebook).
  2. Open the Files panel (folder icon, left side) and upload the private test file into the main folder.
     Name it test.csv (test.json or test.jsonl also work).
  3. Runtime -> Run all.

Local Jupyter
  1. Put reasoning_agent.ipynb and the test file (named test.csv / test.json / test.jsonl) in the same folder.
  2. Kernel -> Restart & Run All.

Test file format
  csv, json or jsonl with one query per row. Columns are detected automatically:
    id (optional)             : id, ID, example_id, question_id
    knowledge base (required) : context, given_info, premises, theory, kb
    query (required)          : statement, question, query, conclusion, hypothesis, text
    gold label (optional)     : flag, label, answer, gold, target   (used only to print the test accuracy)
  If the file has another name, change TEST_PATH in the configuration cell (the cell that starts with
  "# Configuration") to its path.

What the run produces
  submission.csv  one row per test query, columns: id,flag  (True / False)
  The notebook prints TEST INFERENCE TIME, and TEST ACCURACY when the test file contains labels.
  report.pdf, README.txt and submission.zip are regenerated by the last cells.
  The public datasets (RuleTaker, CounterBench, FOLIO) are only used for the experiments section; if they
  cannot be loaded the notebook still runs and predicts the test file. No gold labels are needed to predict.
  Expected run time: a few seconds for the test file; about 20-60 s in total with the public experiments.

Design
------
* rule-based parsers (regular expressions, no learning): controlled English -> signed literals and Horn rules;
  causal sentences -> Boolean structural equations; FOL strings / English -> clauses
* forward chaining with unification and stratified negation as failure (closed world); backward chaining as a cross-check
* counterfactuals: enumeration of possible worlds, abduction -> intervention -> propagation, prior-weighted vote
* resolution refutation: set of support, lightest-clause-first given-clause loop, factoring, subsumption, per-query budget
* output: True if the statement is entailed (or the counterfactual answer is 'yes'), otherwise False
* FOLIO labels False and Uncertain are both mapped to False (binary output)
